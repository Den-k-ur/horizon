## Что объединено

От предыдущего общего снимка `bd541458c` upstream добавил 5871 коммит (1470 по first-parent), изменил 1692 файла. Это число коммитов всей истории, а не число самостоятельных PR.

Разрешены шесть конфликтов: `game.rs`, `game/integrated.rs`, `game/lan.rs`, `game/native_hooks.rs`, `game/remote.rs`, `lib.rs`. Сохранены новые native dispatch, attachments, завершение сервера и сохранение гостей. Самостоятельные NPC, кампании, UUID, приглашения, задания и форматы сохранений форка сохранены.

Native Hooks теперь **359**, расширение **Owned NPC API 1** версионируется отдельно. Actor подключён в `client_lib.rs`: исходный файл не переносился, он собирается новым `horizon-client-lib`. Все 514 публичных native-функций upstream сохранены вместе с семью нашими NPC helpers.

Upstream уже содержит исправления нашего `custom_data` и owner-save. Дублирующий блок отправки `CUSTOM_DATA` удалён; тест проверяет ровно один компонент на wire. Сохранение теперь использует актуальные upstream `write_level_for_role`, `save_leaving_guests`, native flush и события сохранения. Старый shutdown-код не восстанавливался поверх нового.

Тики NPC и кампании перенесены в `tick_world(running)`: один раз для каждого активного серверного уровня после обработки пакетов и блоков. Это проверено самостоятельным NPC в Незере. Сетевой канал NPC сохраняет отдельное согласование версии 1 и лимит 256 КиБ; штатный native-net с меньшим лимитом не подменяет этот канал.
