# Слияние оригинального Horizon — 3 ноября 2026

По поручению пользователя оригинальный `horizon-rust/horizon` слит в рабочую ветку `codex/civilization-upstream-sync` форка `Den-k-ur/horizon`.

## Состояние и сохранность

Включённый upstream: [`6feb4255801c90e306e079a756330668e96eb903`](https://github.com/horizon-rust/horizon/commit/6feb4255801c90e306e079a756330668e96eb903), полученный `git fetch upstream main`. Это снимок main при начале синхронизации. Предыдущая включённая база — `953fbd73c60dda8cdfd2fdeb951717065fa9414d`. Разница: **1502 коммита, 835 изменённых файлов**.

До слияния все 52 локальных файла задач2–8 сохранены независимой копией в `.tools/sync-20261103/pre-merge` и коммитом `3ac29c28e` (Preserve Civilization stages A and B through population and professions). Резервная ветка с полной работой этапа8 — `codex/civilization-stage8-before-merge-20261103`; дополнительная `codex/civilization-before-sync-20261103` хранит прежний HEAD до этого коммита. Для слияния не использовались reset/force-push или удаление изменений.

Оригинальный репозиторий не изменяется; его push URL остаётся `DISABLED_UPSTREAM_PUSH`. В собственном форке рабочая ветка получает merge-коммит, а `origin/main` обновляется только обычным fast-forward до указанного upstream. Отправка без force, с проверкой предков и атомарным обновлением двух удалённых ссылок.

## Конфликты и интеграция

Git сообщил два конфликта: `en_us.json` и `ru_ru.json`. Переводы объединены трёхсторонним сравнением каждого ключа. Несовместимых одновременных изменений значения одного ключа не было. Все **212 ключей Civilization в каждом языке** сохранены, новые ключи upstream добавлены. Итог:718 английских и437 русских ключей.

Rust объединился автоматически. Отдельный обзор подтвердил сохранность команд Civilization, подготовки/тиков/сохранений кампании и собственных NPC, `for_each_player_messaged`, согласования NPC с гостями, очистки/рендеринга зеркал и видимости `teleport_to`. Кампания и реестр NPC остались общими полями Game и не попали в данные отдельного измерения.

Наиболее существенные изменения upstream для проверок: асинхронное сохранение игроков, отложенные гостевые сохранения, закрытие диалогов при ContainerClose, остановка фоновой генерации при выходе, контекст биомного генератора и коллекции сущностей JoinList. Схема Civilization остаётся **v8**, Owned NPC API — **1**, объявленный Native Hooks API — **359** (каталог386 hooks/113 helpers). WASM API теперь7 — это другой контракт. Новых этапов Civilization или месторождений этим слиянием не добавлено.

Тест обновления сохранений расширен для уже существующей v8: сравниваются полный Store и Population, включая назначения/прогресс/счётчики; исключены только три идущих поля часов Population и два прежних таймера обследования. Не создаётся фиктивная `.v8.bak`. Для v8 NPC-профессия, ревизия и статус сравниваются строго; при миграции старых схем сохраняются прежние явные проверки однократной смены служебной профессии. Второй запуск повторно проверяет кампанию и NPC.
