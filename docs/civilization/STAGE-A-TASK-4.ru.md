# Этап A, задача 4 — собственные поселения и основание у колокола

3 ноября 2026. Исходная база форка `bca2bd7c1534f006f21188644c47ed2acbcb1aa2` плюс локальные задачи 2–4; нового коммита нет. Задача 4 реализована и проверена для integrated/LAN. Этап A целиком ещё не завершён; следующий пункт — № 5, поручения по потребностям собственных жителей.

## Получившееся поведение

Поселение существует до цивилизации. Реестр v4 хранит его постоянный ID, колокол, расу/биом, тип происхождения, состояние строительства, владельца и три ключа жителей. После выбора расы сервер ищет подходящее место и создаёт оригинальный небольшой лагерь: три укрытия с кроватями, площадь и колокол. Для человека используются дерево и булыжник, для кошака — песчаник. Перенос происходит после готовности лагеря и проверки безопасной позиции на реальных блоках.

Поиск больше не вызывает locate ванильной деревни: сначала ищется биом в радиусе 6400, затем площадка в пределах 512 блоков вокруг найденной точки, по сетке 32 блока. До четырёх фоновых работ; до 1089 кандидатов, дорогая проверка декорации не более 24 площадок на работу. Это ограниченный поиск, не обещание найти все возможные участки биома. Результат повторно проверяется сервером с учётом загруженного мира, границы, block entities и списка допустимого природного материала. Структуры и жидкости не заменяются. Размещение идёт не более 512 изменённых блоков на поселение в секунду; до первого изменения сохраняется Building, перед Ready — мир. При препятствии остаётся Blocked, `/civ settlement retry` ищет другое место той же расы. Завершённый лагерь и старые поселения никогда не перестраиваются по шаблону.

Жители работают через независимый Owned NPC API 1, без ванильного Villager Brain. Внешний вид жителя Minecraft остаётся допустимым ресурсом отображения. Новые поселения получают отдельного owner `civilization.town-N`, ключи `town-N.quarry/granary/housing`; это постоянные личности до и после основания.

Грамота на колоколе проверяется сервером: обычный мир, действующий колокол, расстояние до 6 блоков, две **целые** кровати с согласованными половинами, собственный живой гражданин, свободное поселение, отсутствие другого членства. Для своего колокола и кроватей можно зарегистрировать поселение без генерации новых блоков; собственным гражданам нужны безопасные места рядом. Грамота расходуется один раз после успешного основания, с откатом инвентаря/реестра при отказе записи. Ванильный житель не требуется.

Основание связывает общину с поселением, даёт ему статус `potential-capital`, а игроку — роль основателя. Признание и проекты остаются нулевыми, стадия — Recognition; Староста сразу не выдаётся. Поручения используют существующих жителей. Компас указывает на колокол своей общины либо привязанного поселения в собственном реестре; восстановление и обновление не размножают предметы.

## Совместимость

Сохранения v1/v2/v3 мигрируют в v4 с точными `.json.v1.bak/.json.v2.bak/.json.v3.bak`. Для существующих общин создаются Legacy-поселения, без блоковых изменений и замены NPC. Сохраняются founder/leader, членство и исторические исполнители, признание, задания, старые owner `civilization` и ключи `civ-N.*`.

Завершённые старые выборы расы участников привязываются к Legacy-поселению. Старый выбор без общины получает собственную точку при следующем входе; сохранённый флаг прибытия не сбрасывается в true, поэтому завершённое прибытие не повторяется. Раса остаётся неизменной.
