# Civilization: гость и признание

Это отдельное приложение из `Den-k-ur/horizon`, ветка `codex/civilization-upstream-sync`. Официальная установка Horizon не заменяется. Сборка включает upstream до `3c68c05d0acabd638dc15158a1d68e121577ec81`, Native Hooks API 40 и наше независимое расширение Owned NPC API 1.

Запуск: `Play-Civilization.cmd` открывает новый мир `Civilization` в выживании. `Play-Demo.cmd` открывает наш проверочный мир с уже пройденными заданиями. Ресурсы Minecraft 26.3 берутся из существующей установки Horizon; в пакет не включены. При необходимости передайте `-Resources "C:\путь\26.3"` скрипту PowerShell.

Миры, настройки и сокет находятся только в `game-data`. Если этот экземпляр уже запущен, сначала сохраните и закройте его. Звук в демонстрационном запуске отключён переменной процесса; настройки устройств не меняются.

## Первый игровой цикл

1. Новый игрок получает книгу «Путь общины» и «Грамоту общины». Для выдачи нужны два свободных места в инвентаре.
2. Найдите деревню в обычном мире: загруженный колокол, минимум две полноценные кровати и один обычный житель в радиусе 32 блоков, по высоте ±12. Поселение, построенное игроками, тоже подходит.
3. Возьмите грамоту и примените её к колоколу с расстояния до 6 блоков. Место становится ратушей общины, а вы — гостем. Постройки деревни не заменяются. Альтернатива с названием: наведитесь на колокол и `/civ found Рассвет`.
4. `/civ quests` покажет трёх самостоятельных представителей общины и их координаты. Нажатие на строку предлагает разговор. Подойдите к нужному NPC ближе 8 блоков и выполните `/civ talk quarry`, `granary` или `housing`.
5. Для каменоломни нужны 16 дубовых брёвен и 32 булыжника; для припасов — 24 пшеницы; для жилья — 32 дубовые доски. Передача: `/civ deliver quarry`, `/civ deliver granary`, `/civ deliver housing`. Все материалы конкретного задания нужны сразу. Именованные и изменённые предметы не списываются.
6. Три проекта дают 60 признания и звание Старосты. `/civ resources` открывает обзор: дерево 0, еда 0, жилых мест 6. Сданные материалы уже потрачены на проекты и не дублируются в запасах.

`/civ` — состояние; `/civ help` — инструкция; `/civ id` — ваш UUID. До основания при потере грамоты используйте `/civ recover-kit`, освободив два места. Участнику уже основанной общины повторный набор не выдаётся.

## Совместная община

Каждый игрок имеет постоянный UUID. Основатель выполняет `/civ invite UUID`, приглашённый — `/civ join civ-1` (нужный ID виден в `/civ`). Задания и признание общие; награда за проект однократна на всю общину. Участник может сдавать материалы, а приглашать новых игроков вправе основатель. Для сетевой игры всем нужен этот форк; отображение самостоятельных NPC согласуется отдельным протоколом версии 1. Это ещё не система дипломатии и договоров между государствами.

## Границы этого среза

Разговоры пока используют консоль чата; отдельного окна диалога и экономики нет. Завершение проекта фиксирует общественное восстановление в учёте, но пока не строит физическую каменоломню или дом. Самостоятельной добычи, назначения труда, войск, камеры сверху, технологий, дипломатии, катаклизмов и новой генерации ещё нет. Личный крафт игрока не ограничивается.

Сохранение находится в `saves/<мир>/horizon-civilization.json`, NPC — в `horizon-owned-npcs.json`. Корректный выход и перезапуск входят в проверку. После аварийного завершения данные Minecraft и файл кампании пока не имеют общего журнала транзакций: сохраните мир после сдачи материалов. Это ограничение текущего прототипа; полный кооперативный хозяйственный цикл потребует устранения этого разрыва.

План развития — `docs/civilization/ROADMAP.ru.md` в исходниках. Фактические результаты проверок и контрольные суммы поставки — в `build.json` и каталоге `proof` рядом с приложением.
